# ReplyKey 隐私说明

## 会发送什么

当你在受支持的桌面微信窗口中复制文字并主动按下热键后，ReplyKey 会把以下内容发送到你在设置中填写的 API 服务：

- 当前复制的消息文本；
- 内存中最近最多 8 次成功交互；
- 用于约束单条中文草稿、语气和长度的系统提示。

连接测试会发送一条最小测试消息。除非你主动触发生成或点击连接测试，否则 ReplyKey 不会调用 API。

## 本地保存什么

- API Key 由 Windows 凭据存储保存。
- API 地址、模型、热键和界面偏好保存在 `%APPDATA%\ReplyKey\config.json`。
- 聊天上下文仅存在于内存；30 分钟无操作、手动清空或退出程序都会移除。
- 日志只包含固定事件元数据，不包含 API Key、聊天原文或生成草稿。

## ReplyKey 不会做什么

- 不读取微信聊天数据库、文件或联系人信息；
- 不截图、不做 OCR、不监控键盘输入；
- 不上传配置文件或日志；
- 不把会话同步到 ReplyKey 自有云端；
- 不自动发送消息。

你选择的 API 服务可能按其自己的条款处理输入。使用前请确认服务地址可信，并阅读该服务的隐私政策。
