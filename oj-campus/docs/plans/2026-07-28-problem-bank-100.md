### Catalog entry template

Use this form throughout the three catalog modules:

```python
SeedProblem(
    title="示例题名",
    difficulty="easy",
    tags=("基础",),
    statement="清晰、完整的中文题面，并说明关键约束。",
    input_text="输入格式与范围。",
    output_text="输出格式。",
    cases=(
        SeedCase("样例输入\n", "样例输出\n", is_sample=True),
        SeedCase("隐藏输入 1\n", "期望输出 1\n"),
        SeedCase("隐藏输入 2\n", "期望输出 2\n"),
        SeedCase("边界输入\n", "边界输出\n"),
    ),
    time_limit_ms=1000,
)
```

Every problem statement must provide numeric or size constraints sufficient for a student to select an algorithm and integer type. Keep each static case small enough to review, but include at least one case that distinguishes the intended algorithm or edge behavior.
